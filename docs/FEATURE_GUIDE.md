# 기능 설명서 — 4대 핵심 기능

이 문서는 대시보드의 4개 탭이 각각 무엇을 하는지, 화면에서 어떤 순서로 조작하는지, 그 뒤에서 어떤 계산이
일어나는지를 팀원·발표 준비용으로 정리한 문서입니다. 전체 배경/데이터/모델 학습 과정이 궁금하면
[`PROJECT_OVERVIEW.md`](../PROJECT_OVERVIEW.md)를, 빠른 소개만 필요하면 [`README.md`](../README.md)를
먼저 보세요.

대시보드는 상단에서 공정 4개(isolation / trench / gate / metal) 중 하나를 고르면, 아래 4개 탭이 그
공정 기준으로 동작합니다.

---

## 1. 공정 예측 · 평가 · 추천

**한 줄 요약**: Recipe 조건(또는 목표 품질)을 넣으면, AI 모델이 예상 Wafer 품질을 예측하고 점수를 매기고,
필요하면 어떤 파라미터를 어떻게 바꿔야 할지까지 알려주는 핵심 시뮬레이터입니다.

**누가 언제 쓰는지**: 새 Recipe를 시도하기 전에 "이 조건으로 하면 결과가 어떨까"를 미리 확인하고 싶을 때,
또는 "이런 품질을 원하는데 지금 Recipe에서 뭘 바꿔야 하나"를 알고 싶을 때 씁니다.

**화면 흐름**: 화면 상단에서 두 모드 중 하나를 라디오 버튼으로 고릅니다.

- **🎯 목표 품질 모드** (목표 스펙 → 변경점 추천): 원하는 목표 CD/Depth 값을 입력하면, 기준 Recipe를
  출발점으로 파라미터를 하나씩 바꿔보면서(One-Factor-at-a-Time) 목표에 가까워지는 방향을 찾아 추천
  표로 보여줍니다.
- **📋 Recipe 직접 입력 모드** (Recipe 값 → 예상 품질): Stage별 Time/RF Bias/Pressure/Gas 값을 직접
  넣으면, 아래 순서로 결과가 나옵니다.
  1. 예상 품질 예측 (Top/Mid/Bottom CD, Depth, Uniformity, Pass Rate, Defect)
  2. 목표 스펙 대비 평가 (미달 항목 우선순위 표시)
  3. 최적 Recipe 추천 (관측된 Recipe 중 점수가 가장 높은 것)
  4. 개선 효과 비교표

두 모드 모두, 입력값이 AI 모델이 학습 때 본 범위를 벗어나면 예측을 실행하기 전에 먼저 경고하고 막습니다
("그래도 이 값으로 실행" 버튼으로 우회 가능, 이땐 결과에 "신뢰도 낮음" 표시가 함께 뜹니다).

**내부적으로 어떤 계산이 일어나는지**: 항목별로 따로 학습된 RandomForest/XGBoost 모델이 Wafer의 25개
측정 지점(Site) 각각의 값을 예측하고, 이를 평균·표준편차로 묶어 Wafer 단위 결과를 만듭니다. 점수는
"Pass Rate 60% + Uniformity 25% + 목표 근접도 15%"로 계산됩니다. 자세한 공식은
[`PROJECT_OVERVIEW.md` §6](../PROJECT_OVERVIEW.md)을 참고하세요.

**한계/주의사항**: 관측된 Recipe가 공정당 16개뿐이고 순차적으로 파라미터를 바꿔온 이력이라, 모델이 잡아낸
것은 "파라미터가 원인이다"라는 인과관계가 아니라 연관성입니다. 장비/챔버 조합 중 실제로 관측되지 않은
조합은 예측 자체가 차단됩니다.

## 2. Process Dashboard

**한 줄 요약**: 지금까지 쌓인 실제 측정 데이터를 Recipe(Rev)별로 한눈에 비교하고 분석하는 화면입니다.
AI 예측이 아니라 **실측 데이터 집계**가 중심입니다.

**누가 언제 쓰는지**: "지금까지 어떤 Recipe가 제일 좋았는지", "이 Recipe의 실제 측정값 분포는 어땠는지"를
확인하고 싶을 때 씁니다.

**화면 흐름**: 최상단에 항상 보이는 **Rev별 스코어링 순위표 + Best case 하이라이트**가 있고, 그 아래로는
필요할 때만 펼쳐보는 접이식 섹션들이 순서대로 있습니다.

1. Rev별 스코어링 순위표 (최상단, 항상 표시) — 실측 데이터 기준 종합 점수 순위 + 막대그래프
2. AI 분석 — 이 Recipe/공정에 대한 요약 문장(실측 데이터 기반 분석 문구)
3. Recipe 비교 — Rev끼리 나란히 비교
4. 선택 Recipe Summary — 현재 선택된 Recipe의 요약 정보
5. Rev별 품질 변화 — 시간(Rev) 흐름에 따른 품질 추이 그래프
6. Wafer 단위 품질 결과 — Wafer 하나하나의 품질 시각화
7. Wafer 단면 Profile — Wafer를 Edge → Center → Edge 순서로 자른 단면 그래프 (기존 2D 방사형 Wafer
   Map만으로는 보기 어려웠던 구간별 추이를 보완)
8. Zone별 분석 — Center/Mid/Edge/Extreme Edge 구역별 분석

**내부적으로 어떤 계산이 일어나는지**: Rev별 스코어링은 AI 모델 예측이 아니라 `Wafer_Summary` 실측치를
그대로 집계해서 점수화한 것입니다(공식은 시뮬레이터와 동일한 `ml_engine/scoring.py` 공유). AI 분석
문장의 "Defect 3건 초과 Wafer 몇 장" 같은 문구도 모델 예측이 아니라 실측 `Total_Defect_Count` 컬럼을
그대로 집계한 것입니다.

**한계/주의사항**: 없음 (실측 데이터 조회 위주라 모델 관련 한계가 크게 적용되지 않습니다).

## 3. Parameter 변경 이력 조회

**한 줄 요약**: Recipe가 Base부터 Rev15까지 오면서 어떤 파라미터가 언제, 얼마나 바뀌었는지 이력을
조회하는 기능입니다.

**누가 언제 쓰는지**: "이 파라미터가 어느 Rev에서 바뀌었지?", "그 변경으로 품질이 어떻게 달라졌지?"를
추적하고 싶을 때 씁니다.

**화면 흐름**:
1. 필터 3단계 선택 — Equipment / 변경 파라미터 유형(Time·RF Bias·Pressure·Gas 등) / 세부 파라미터
2. 조건에 맞는 Revision들이 카드 형태로 나열됩니다(최신 Revision이 위로). 각 카드에는:
   - 그 Revision에서의 품질 변화 요약과 KPI(목표 대비 변화)
   - 바뀐 파라미터의 Before/After 비교표

**내부적으로 어떤 계산이 일어나는지**: `history_utils.py`가 `Recipe_Master`에서 Rev끼리 값을 비교해서
어떤 파라미터가 바뀌었는지 자동으로 찾아내고(`Changed_Params_This_Rev` 컬럼과 실제 값 비교 병행), 그
Rev 전후의 실측 품질 변화를 같이 보여줍니다. 별도 AI 모델 예측은 쓰이지 않습니다(전부 실측 데이터 기반).

**한계/주의사항**: 1-Stage 공정(gate/metal)과 다단계 공정(isolation/trench)은 파라미터 이름 구조가
달라서(접두사 유무), 라벨 표시 로직이 공정 종류를 구분해서 처리합니다 — 화면에는 그대로 자연스럽게
보이니 사용자가 신경 쓸 부분은 아닙니다.

## 4. 신규 공정 품질 예측

**한 줄 요약**: 아직 데이터가 없는 새로운 Layer 조합(신규 공정)을 입력하면, 가장 비슷한 기존 공정의
실측 평균값을 참고값으로 보여주는 기능입니다. **주의: 이건 AI가 새로 학습해서 내놓는 진짜 예측이
아니라, 기존 데이터 중 가장 비슷한 사례를 찾아 보여주는 참고용 근사치입니다.**

**누가 언제 쓰는지**: 아직 우리 시스템에 없는 새로운 공정(예: 다른 물질 조합)을 검토하는 초기 단계에서,
"기존에 비슷한 공정이 있었다면 대략 어느 정도 수준이었나"를 가늠하고 싶을 때 씁니다.

**화면 흐름**: 7단계로 구성됩니다.
1. **기본정보** — 공정명/설명 입력, 현재 선택된 Equipment 참고 표시
2. **Layer 구조** — Etch할 물질을 위에서부터 순서대로 입력(드롭다운, 목록에 없는 물질은 "기타 직접입력")
3. **Etch Recipe 입력** — Mask/Substrate를 제외한 나머지 레이어마다 Time/RF Bias/Pressure + Gas 조건 입력
4. **기존 유사 Recipe 참고** — 입력한 Layer 구성과 겹치는 정도가 가장 높은 기존 공정을 자동으로 찾아,
   그 공정의 파라미터 실측 범위(최소~최대)를 보여줌
5. **Before/After 단면도** — 레이어 구성을 색상 블록으로 시각화, Etch 대상 레이어만 해칭 표시로 구분
6. **품질 예측 버튼**
7. **결과 카드** — 4번 단계에서 찾은 "가장 비슷한 기존 공정"의 실측 평균값을 그대로 보여주며,
   "예시(참고값 기반 근사치)"라고 화면에 명확히 라벨링

**내부적으로 어떤 계산이 일어나는지**: 실제 ML 예측 모델은 쓰이지 않습니다. Mask/Substrate만 규칙 기반으로
자동 제외하고, 나머지는 물질 이름 매칭으로 기존 4개 공정 중 가장 겹치는 공정을 찾아 그 공정의 실측
평균값을 그대로 재사용하는 방식입니다.

**한계/주의사항**: 왜 진짜 AI 예측이 아닌지 — 현재 데이터 구조는 Stage(공정 단계) 단위로 분해된 라벨이
없고, 학습된 공정 자체도 4개뿐이라 임의의 새 Layer 조합에 대한 실질적인 예측 모델을 만들 수가 없습니다.
그래서 정직하게 "참고값"이라고만 제공합니다. 자세한 배경은
[`PROJECT_OVERVIEW.md` §11(한계)](../PROJECT_OVERVIEW.md)를 참고하세요.
